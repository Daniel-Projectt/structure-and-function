# Structure & Function - Study Lab

Anatomy and physiology study tool: spaced-repetition flashcards, practice exams with application (second-order) questions, matching, labeled vector diagrams with hidden labels, and public-domain anatomical plates with a recognition quiz.

Live: https://daniel-projectt.github.io/structure-and-function/

## Build

Content lives in src/. Run: sh build.sh
That concatenates the pieces into index.html and runs the test suite (src/test.js).

## Plates

Images in img/ come via Wikimedia Commons:
- Gray's Anatomy (1918) and Encyclopaedia Britannica (1911) plates - public domain.
- Skeleton figures by Mariana Ruiz Villarreal (LadyofHats) - public domain.
- Anterior muscles figure by Mikael Haggstrom, assembled from Gray's plates - public domain.
